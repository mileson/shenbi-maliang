# Contributing

Contributions are welcome when they improve the reusable workflow, scripts, documentation, or privacy safeguards.

Before opening a pull request:

- Do not include real portrait photos, generated private albums, board images, API keys, tokens, or local credentials.
- Keep user-facing instructions clear for non-developers.
- Preserve the Skill rule that a real persona image is required before generation.
- Run Python syntax checks for scripts you change.

For behavior changes, update `README.md` and `SKILL.md` together so the public page and runtime instructions stay aligned.
